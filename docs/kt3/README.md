## Что остаётся до финальной сдачи

Снимок для рецензирования кода вместе с UML: коммит `b4be7f6`.
[Инструкция напарнику](reviewer.md) содержит команды запуска и форму замечаний.
Автономный комплект для пересылки собирается командой
`python3 scripts/package_kt3_review.py` из корня репозитория.

1. Выбрать напарника, получить ссылку на его репозиторий и точный коммит КТ3.
2. Проверить его код и получить настоящую рецензию на свою Java-версию. Заполнить `kt3/review/review.md` текстами замечаний, местами в коде и решениями автора. Исправления по полученным замечаниям оформить отдельными коммитами.
3. Уточнить личную самооценку компетенций. Сейчас таблицы описывают подтверждённые материалы проекта, а не самостоятельное владение автора всеми технологиями.
4. Учесть замечания преподавателя к КТ2, если они были. Текст таких замечаний пока не предоставлен.
5. После этих шагов дополнить прежний отчёт разделом «Реализация на Джаве и организационный раздел», добавить рисунки, подписи, ссылки и обновить содержание. Проверить вёрстку.
6. Обновить Git-выгрузку и собрать `ИКБО-10-24_НовожиловВА_КТ3.zip` по структуре памятки. Процедурный Python и скомпилированные файлы в ZIP КТ3 не включать.

## Воспроизводимые проверки

Из корня репозитория:

```sh
sh kt3/src/java/test.sh
python3 scripts/check_kt3_parity.py
python3 scripts/measure_kt3.py
python3 scripts/build_kt3_market.py
python3 scripts/build_kt3_uml.py
```

Для UML нужны JDK (`javap`) и PlantUML; программа Java от PlantUML не зависит. Сигнатуры полей и методов извлекаются из `out/`, поэтому перед перестроением диаграммы требуется сборка. `classes.puml` не содержит удалённых include и может рендериться локально. Схема пакетов перестраивается командой `plantuml -charset UTF-8 -tpng docs/kt3/packages.puml`.
