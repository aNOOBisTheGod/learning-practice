## Интерпретация для проекта

Java и SQL прямо встречаются в требованиях пяти вакансий из десяти. Для текущей программы важнее сначала закрепить коллекции, контракты объектов и запросы к данным, чем добавлять распределённую инфраструктуру. REST/API также встречается в пяти позициях: это следующий шаг после устойчивой CLI-версии и подключения БД на КТ4. Git/GitLab упомянуты в пяти вакансиях, CI/CD — в четырёх; воспроизводимая сборка и автоматические проверки связывают разработку с эксплуатацией.

Все три аналитические позиции требуют UML и BPMN. Это подтверждает связь диаграмм КТ2/КТ3 с рабочими задачами аналитика. Обе QA-позиции используют Java и JUnit/TestNG; автономные assert-проверки текущего проекта полезны как старт, но не заменяют практику тестового фреймворка. Linux/Unix упомянуты в трёх вакансиях, в том числе у тестировщика; чтение логов и запуск приложения на сервере нужны не только DevOps-инженеру.

Восемь позиций ориентированы на опытных специалистов, если считать явно заявленные Middle/Senior и требования от трёх лет; V01 и V05 дают ориентир на начало карьеры. Коммерческий стаж из вакансий не заменяется учебным проектом: приоритеты ниже описывают подготовку к следующему уровню, а не обещание немедленного соответствия всем позициям.

## Уточнения к кодированию требований

- **V01**: Kubernetes описывает архитектуру проекта; не включён в счётчик требований.
- **V02**: Spring Boot, Docker/Kubernetes и Kafka/RabbitMQ перечислены как варианты внутри групп, а не как одновременное требование всех инструментов. Опыт PostgreSQL/MySQL/Oracle — преимущество. Содержание получено из индексированной страницы сайта работодателя; прямое открытие ссылки при проверке вернуло сетевую ошибку, активность вакансии на сайте не подтверждена.
- **V03**: Kubernetes указан в стеке проекта, отдельно в требованиях к кандидату не выделен.
- **V04**: Учитывается именно вакансия Java AQA, а не соседние вакансии компании.
- **V05**: Selenium/Playwright, отчётность Allure и работа с брокерами перечислены как преимущества.
- **V06**: Java и PostgreSQL названы стеком продукта; не засчитываются как явно требуемый опыт разработки аналитика.
- **V07**: Вакансия из Беларуси включена как отдельный географический сегмент; её условия не обобщаются на Москву. SQL явно не назван, поэтому не засчитывается.
- **V08**: ATAM и опыт ERP/CRM/АБС обозначены как преимущества.
- **V09**: Знание PostgreSQL не приравнивается автоматически к явному требованию писать SQL-запросы.
- **V10**: Python/Go — преимущество, не обязательное требование.
